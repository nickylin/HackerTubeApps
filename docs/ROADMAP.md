# Roadmap

## v0.1.0 (this release)
- Phone + tablet Compose app, TV leanback launcher in the same APK
- Feed, search, browse, playlists, detail, local library
- Offline fallback classics, GitHub Actions APK builds

## v0.2
- Native Compose for TV home/detail with proper D-pad focus
- Category and playlist pagination against the full dataset
- Share sheet ("Send to HackerTube"), deep links `hackertubeapps://video/<vid>`

## v0.3
- Optional full offline dataset download (the ZIP Karpathy published)
- Semantic search if the API exposes it; on-device fallback otherwise
- Home-screen widget: "One HN classic a day"

## Store
- Google Play listing (copy in docs/PLAY_STORE.md), privacy: no data collected
- F-Droid submission
